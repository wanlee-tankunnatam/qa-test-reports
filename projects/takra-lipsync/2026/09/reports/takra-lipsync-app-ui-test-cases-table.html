Precondition

Test Steps

  1. ดับเบิลคลิกไอคอน "TAKRA Lib-Sync" บนหน้า Desktop แล้วรอหน้า "กำลังเปิดระบบ TAKRA Lib-Sync..." จนหาย — ถ้าขึ้นหน้า "เชื่อมบัญชี TikTok ของคุณก่อนเริ่ม" ให้กด "🔗 เข้าสู่ระบบ TikTok" แล้วสแกน QR ด้วยบัญชี TikTok ทดสอบ จนเข้าหน้าเตรียมไลฟ์

  4. ในแอปกด "🗣 เริ่มพูด" แล้วเปิดดูไลฟ์จากมือถืออีกเครื่องประมาณ 2 นาที
  5. กด "⏹ หยุดพูด" แล้วกด End LIVE ใน Studio

Expected Result

  • preview ใน Studio เห็นภาพ avatar ครอป 9:16 ไม่เห็นแถบควบคุมขาวด้านขวา และมีเสียงเข้า meter
  • ฝั่งผู้ชมเห็นภาพลื่น ได้ยินเสียง avatar และปากตรงเสียง
  • ไลฟ์จบครบ ~2 นาทีโดยไม่ถูก TikTok ตัด — จดผู้ชม/อาการ/ข้อความเตือนจากระบบลง Actual
