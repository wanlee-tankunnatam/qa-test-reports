▸T1225.1 หน้าสร้าง/แก้สคริปต์ — content ในบล็อกเรียงลงมาทีละแถว เต็มความกว้างของบล็อก Happy Path UI P0 รอเทส
หน้าสร้าง/แก้สคริปต์ — content ในบล็อกเรียงลงมาทีละแถว เต็มความกว้างของบล็อก
🧩 Epic TAKRA-1225 · Priority: P0 · UI · ประเภท: Happy Path (flow ปกติ) · TAKRA-1225 · หน้าสร้างสคริปต์ใช้งานง่ายขึ้น — content เต็มความกว้าง

Precondition

  • บัญชีเจ้าของ workspace ทดสอบ
  • มีสคริปต์ที่บล็อกหนึ่งมี content อย่างน้อย 3 ตัว (หรือสร้างใหม่แล้วตั้ง "จำนวนสคริปต์:" = 3)

Test Steps

  1. เปิดเว็บ TAKRA AI แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ workspace บนจอกว้าง (≥1280px)
  2. ไปที่เมนู "คลังสคริปต์" แล้วกดเปิดสคริปต์ที่เตรียมไว้เพื่อแก้ไข
  3. ดูบล็อกที่กางอยู่ สังเกตการวาง content ("Content 1", "Content 2", "Content 3") และกล่องประใต้ content ที่ขึ้นว่า "มี 3 จาก 5 สคริปต์"
  4. กลับไปเมนู "คลังสคริปต์" กด "สร้างสคริปต์" เลือก "เริ่มจากบล็อกเปล่า" แล้วสังเกตแบบเดียวกัน

Expected Result

  • content ทุกตัวเรียงลงมาทีละแถว (คอลัมน์เดียว) — ไม่มี content 2–3 ตัวยืนเรียงข้างกันในแถวเดียว
  • ช่องพิมพ์บทพูดของแต่ละ content กว้างเท่าการ์ดบล็อก
  • กล่องประ "มี N จาก 5 สคริปต์" เป็นแถวเต็มความกว้างเหมือนกัน
  • เหมือนกันทั้งหน้าแก้สคริปต์และหน้าสร้างสคริปต์
