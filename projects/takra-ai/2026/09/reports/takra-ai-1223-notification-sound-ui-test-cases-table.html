🧩 Epic TAKRA-1223 · Priority: P0 · UI · ประเภท: Happy Path (flow ปกติ) · TAKRA-1223 · เสียงกระดิ่งเมื่อมีการแจ้งเตือนใหม่ในไลฟ์ — ปุ่มกระดิ่ง "แจ้งเตือน" แถบบนของแพลตฟอร์มไลฟ์ (⛔ ยังไม่มีโค้ด)

Precondition

  • บัญชีเจ้าของ workspace ทดสอบบน UAT
  • เปิดเสียงเครื่องไว้
  • มีไลฟ์ที่กำลังออกอากาศอยู่ และมีไลฟ์อีกรอบที่พร้อมเริ่ม (สำหรับทำให้เกิดแจ้งเตือน)

Test Steps

  1. เปิดเว็บ TAKRA AI (UAT) แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ workspace แล้วไปที่เมนู "แพลตฟอร์มไลฟ์"
  2. ไปที่เมนู "ห้องคุมไลฟ์" ของไลฟ์ที่กำลังออกอากาศ แล้วคลิกที่หน้าหนึ่งครั้ง
  3. ทำให้เกิดแจ้งเตือนใหม่ โดยเริ่มออกอากาศไลฟ์อีกรอบจากอีกเครื่อง/อีกหน้าต่าง (ให้เกิดแจ้งเตือน "เริ่ม Live")
  4. ฟังเสียงจากเครื่อง และดูปุ่มกระดิ่งที่แถบบนขวา

Expected Result

  • ได้ยินเสียงกระดิ่ง 1 ครั้ง ทันทีที่แจ้งเตือนใหม่เข้ามา
  • ปุ่มกระดิ่งขึ้นตัวเลขรายการใหม่ (อ่านว่า "แจ้งเตือน · N ใหม่")
  • กดกระดิ่งแล้วเห็นรายการใหม่ใน "การแจ้งเตือน" ติดป้าย "ยังไม่ได้อ่าน"
ที่มา: TAKRA-1223 "[FE] เพิ่มเสียงกระดิ่งเมื่อมีการแจ้งเตือนใหม่" (ยังไม่ groom) · ปุ่มกระดิ่ง "แจ้งเตือน" แถบบนของแพลตฟอร์มไลฟ์
