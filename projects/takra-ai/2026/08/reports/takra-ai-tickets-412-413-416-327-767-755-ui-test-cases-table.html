E2E · ตั้งค่าแจ้งเตือน 2 หน้าจอ → เริ่ม/จบไลฟ์ → กระดิ่งขึ้นรายการจริง → "อ่านทั้งหมด" → รีเฟรชแล้วตัวเลขไม่กลับมา
Priority: P0 · E2E · ประเภท: Happy Path (flow ปกติ) · 🔄 Full E2E Flow — วิ่งครบลูปข้ามใบงาน (Studio → ไลฟ์ → สรุป · แจ้งเตือน → ยกเลิกอีเมล)

Precondition

  • บัญชีเจ้าของ workspace ที่เข้าได้ทั้งหน้า "ตั้งค่า" และหน้าตั้งค่าห้องคุมไลฟ์
  • รอบไลฟ์ทดสอบที่ออกอากาศได้บน UAT

Test Data

  • สวิตช์ที่ใช้ทดสอบ: ในแอป ของ "คำเสี่ยงถูกพูด"

Test Steps

  1. เปิดเว็บ TAKRA AI (UAT) เข้าสู่ระบบแล้วไปที่ "ตั้งค่า" → "การแจ้งเตือน" ปิดสวิตช์ "ในแอป" ของ "คำเสี่ยงถูกพูด" แล้วกด "บันทึก"
  2. เปิดหน้าตั้งค่าของฝั่งห้องคุมไลฟ์ (/live/settings) ตรวจว่าสวิตช์ตัวเดียวกันปิดอยู่ แล้วเปิดกลับและกด "บันทึก" ที่หน้านี้
  3. กลับไปที่ "ตั้งค่า" → "การแจ้งเตือน" รีเฟรช แล้วตรวจว่าสวิตช์ตัวนั้นเปิดกลับแล้ว
  4. เริ่มออกอากาศรอบไลฟ์ทดสอบจนสถานะเป็นกำลังไลฟ์ แล้วจบไลฟ์
  5. กดไอคอนกระดิ่ง อ่านรายการ กด "อ่านทั้งหมด" แล้วรีเฟรชหน้าและดูตัวเลขบนกระดิ่งอีกครั้ง

Expected Result

  • ค่าที่บันทึกจากหน้า "ตั้งค่า" อ่านได้ที่หน้าตั้งค่าห้องคุมไลฟ์ และแก้จากหน้านั้นแล้วหน้าแรกก็เห็นค่าตาม (ค่าชุดเดียวกันทั้งสองจอ)
  • กระดิ่งขึ้นรายการของไลฟ์รอบนี้จริง ไม่ใช่ข้อมูลตัวอย่าง
  • ตัวเลขบนกระดิ่งตรงกับจำนวนแถวที่ติดป้าย "ยังไม่ได้อ่าน"
  • กด "อ่านทั้งหมด" แล้วป้ายหายทุกแถวและตัวเลขบนกระดิ่งหาย
  • รีเฟรชแล้วตัวเลขไม่กลับมา — ทั้งค่าสวิตช์และสถานะอ่านถูกจำไว้จริง
