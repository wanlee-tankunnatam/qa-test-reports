Priority: P0 · UI · ประเภท: Happy Path (flow ปกติของการไลฟ์) · 🧹 Round 1 — เคลียร์ของค้างที่บล็อกความเชื่อมั่น (สัปดาห์นี้)

Test Steps

  1. เปิดเว็บ TAKRA Rerun แล้วเข้าสู่ระบบด้วยบัญชี UAT → ไปที่เมนู "บัญชีไลฟ์" แล้วเปิดห้องของบัญชีที่จะใช้ทดสอบ
  2. เตรียมบัญชีที่มีสินค้าในตะกร้า ≥ 3 ชิ้น และคลิปที่มีตารางปัก 2 cue (เช่น สินค้า A ที่ 00:30, สินค้า B ที่ 01:30)
  3. ตั้งเพลย์ลิสต์ 2 คลิปสั้น (รวม ≈ 2 นาที) เพื่อให้วนรอบเร็ว
  4. กด Go Live และเปิดไลฟ์ดูจากมือถือเครื่องที่สอง
  5. รอบที่ 1: จดเวลาและสินค้าที่ถูกปักจริงบนจอผู้ชม เทียบกับ cue ที่ตั้งไว้
  6. ปล่อยให้เพลย์ลิสต์วนครบ ≥ 3 รอบ (ผ่าน playlist wrap ≥ 2 ครั้ง) และจดการปักของทุกรอบ
  7. ระหว่างรอบที่ 2 แก้ตารางปักจากหน้าเว็บ (เพิ่ม/สลับสินค้า 1 cue) แล้วดูรอบถัดไป

Expected Result

  • สินค้าถูกปักตรงตัว ตรง cue ทุกครั้ง — ไม่ปักผิดชิ้น ไม่ข้าม cue
  • หลัง playlist วนรอบใหม่ (wrap) จุดยึดเวลา cue ต้องเริ่มนับใหม่ตามคลิป ไม่เลื่อน/ค้างจากรอบก่อน
  • การแก้ตารางระหว่างไลฟ์มีผลในรอบถัดไปโดยไม่ต้อง restart ไลฟ์
  • ไม่มีอาการตามบั๊กเดิม TAK-559 / TAK-573 / TAK-588 กลับมา
