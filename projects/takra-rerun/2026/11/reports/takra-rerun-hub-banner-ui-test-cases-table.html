Test Steps

  1. เปิดเบราว์เซอร์ Chrome ไปที่ https://uat-hub.takra.ai แล้วเข้าสู่ระบบด้วยบัญชีแอดมิน Hub (UAT)

  3. เปิดแอป TAKRA Rerun (รุ่น UAT) บนเครื่อง Windows แล้วเข้าสู่ระบบด้วยบัญชี UAT รอให้หน้า "บัญชีไลฟ์" โหลดเสร็จ แล้วกดลูกศรขวาของแถบโปรโมชั่นทีละครั้งจนวนครบ พร้อมจดตัวเลขลำดับใต้แถบ (เช่น "1/3") กับเลขในรูปแต่ละครั้ง
  4. สังเกตตำแหน่งแถบ ลำดับรูป ขอบรูป และมุมแถบว่ามีปุ่มปิด (×) หรือไม่

Precondition

  • บัญชี UAT ของ Rerun มีแพ็กเกจที่ใช้งานได้ (ไม่ติดจอ "ต้องมีแพ็กเกจจึงจะใช้งานได้") · บัญชีแอดมิน Hub (UAT) มีสิทธิ์แก้ "เนื้อหาหน้าเว็บ"
  • เครื่อง Windows ตั้งเบราว์เซอร์เริ่มต้นไว้แล้ว

Test Data

  • QA-BN-1: "ชื่อแบนเนอร์" = QA-BN-1 ราคาแพ็กเกจ · รูป qa-bn-1.jpg (JPG 1440×488 มีเลข 1 ตัวใหญ่) · "ปลายทาง" = "ราคาและแพ็กเกจ (/pricing.html)"
  • QA-BN-2: "ชื่อแบนเนอร์" = QA-BN-2 คู่มือ · รูป qa-bn-2.png (PNG 1440×488 มีเลข 2) · "ปลายทาง" = "ลิงก์อื่น (พิมพ์เอง)" ช่อง "ลิงก์" = https://help.takra.ai/livestream/
  • QA-BN-3: "ชื่อแบนเนอร์" = QA-BN-3 รายละเอียดโปร · รูป qa-bn-3.webp (WebP 1440×488 มีเลข 3) · "ปลายทาง" = "หน้ารายละเอียดโปร (สร้างหน้าใหม่)" ช่อง "หัวข้อ" = QA-BN-3 รายละเอียดโปร ("ลิงก์ของหน้า" ใช้ค่าที่ระบบตั้งให้)
  • ทุกใบ: "แสดงที่ไหน" = ติ๊ก "ตะกร้า Rerun" อย่างเดียว · "ช่วงเวลา" ว่าง ("เริ่มแสดง"/"หยุดแสดง") · สวิตช์ = "แสดงบนหน้าเว็บ"

Test Steps

  1. เปิดเบราว์เซอร์ Chrome ไปที่ https://uat-hub.takra.ai แล้วเข้าสู่ระบบด้วยบัญชีแอดมิน Hub (UAT)
  2. ไปที่เมนู "เนื้อหาหน้าเว็บ" แท็บ "แบนเนอร์" — ถ้ามีใบอื่นที่ป้าย "เผยแพร่" และบรรทัดรองขึ้น "ตะกร้า Rerun" หรือ "ทุก platform" ให้จดชื่อไว้ แล้วกด "แก้ไข" สลับเป็น "ไม่แสดงบนหน้าเว็บ (ร่าง)" กด "บันทึก" ให้หมดก่อน แล้วกด "เพิ่มแบนเนอร์" สร้าง 3 ใบตาม Test Data ทีละใบ — แต่ละใบ อัปโหลด "รูปแบนเนอร์" (คลิกเพื่อเลือกรูป) กรอก "ชื่อแบนเนอร์" ติ๊ก "ตะกร้า Rerun" ในหัวข้อ "แสดงที่ไหน" เลือก "ปลายทาง" ตาม Test Data เปิดสวิตช์เป็น "แสดงบนหน้าเว็บ" แล้วกด "บันทึก" จากนั้นใช้ปุ่มลูกศร "เลื่อนขึ้น"/"เลื่อนลง" เรียงให้ QA-BN-1 → QA-BN-2 → QA-BN-3 อยู่บนสุดของรายการ แล้วรอ 1 นาที
  3. เปิดแอป TAKRA Rerun (รุ่น UAT) บนเครื่อง Windows แล้วเข้าสู่ระบบด้วยบัญชี UAT รอให้หน้า "บัญชีไลฟ์" โหลดเสร็จ แล้วคลิกรูปใบที่ 1 ในแถบโปรโมชั่น

  5. สังเกตหน้าเว็บที่เปิดในเบราว์เซอร์แต่ละครั้ง และหน้าต่างแอป
