🧩 Epic TI-714 · Priority: P0 · E2E · ประเภท: Happy Path (flow ปกติ) · Journey แจ้งเตือน Telegram · ไลฟ์มีปัญหาบนจอ
📌 หมายเหตุ: FAIL ถ้ากลุ่มทดสอบไม่ได้ข้อความทดสอบ หรือหน้าโชว์ token เต็ม · สวิตช์แนบภาพเปิดได้หลังเปิดการส่งเท่านั้น จึงต้องเปิดการส่งก่อน · เคส TC-JRN-C.2 และเคสไลฟ์ที่ส่ง Telegram ใช้การตั้งค่านี้ต่อ

Precondition

  • บัญชีเลือกพื้นที่ทำงานไว้แล้ว และพื้นที่ทำงานนี้บนเครื่องนี้ยังไม่เคยตั้งค่า Telegram
  • บอททดสอบของ QA ที่สร้างจาก @BotFather (มี token) และถูกเพิ่มเข้ากลุ่ม Telegram ทดสอบแล้ว

Test Data

  • บัญชีที่ใช้ (UAT): qa.owner@realfactory.co.th · บทบาท "เจ้าของ"

Test Steps

  1. เปิดแอป TAKRA Insight (UAT) แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ กดปุ่มโปรไฟล์ที่มุมล่างของเมนูซ้าย เลือก "ตั้งค่า" แล้วกด "แจ้งเตือน Telegram" ที่แถบหมวดด้านซ้าย แล้วดูสถานะของหน้า
  2. วาง token ของบอททดสอบในช่อง "วาง bot token" แล้วกด "บันทึก" รอแอปตรวจกับ Telegram และค้นหากลุ่มให้เอง
  3. เลือกกลุ่มทดสอบจากรายการกลุ่มที่บอทอยู่ แล้วกด "บันทึก" ในขั้นที่ 2
  4. กด "ส่งข้อความทดสอบ" ในขั้นที่ 3 แล้วเปิดกลุ่มทดสอบในแอป Telegram ดูข้อความที่เข้ามา
  5. กลับมาที่หน้าเดิม กดสวิตช์ "ส่งแจ้งเตือนเข้ากลุ่ม" ให้เปิด แล้วอ่านคำเตือนของแถว "แนบภาพโฮสต์ตอนเกิดเรื่อง" ก่อนกดสวิตช์นั้นให้เปิด
  6. กด "ดูตัวอย่างข้อความ" แล้วดูกรอบตัวอย่าง
  7. อ่านรายการใต้หัวข้อ "เรื่องที่ส่ง" จนจบ

Expected Result

  • ทางเข้า: เมนูโปรไฟล์มีแค่ "ตั้งค่า" (ไม่มี "แจ้งเตือน Telegram" แยกแล้ว) · หน้า "แจ้งเตือนเข้า Telegram" อยู่ในหน้าตั้งค่าที่มีแถบหมวดด้านซ้าย ป้ายการ์ด "เชื่อมบอทกับกลุ่ม" เป็น "ยังไม่ได้ตั้งค่า" และสวิตช์ส่งแจ้งเตือนกดไม่ได้ ("กดได้หลังส่งข้อความทดสอบผ่าน")
  • บันทึก token: ขั้นที่ 1 ขึ้นเครื่องหมายถูก แสดง "บอท @{ชื่อบอท} · token ••••{4 ตัวท้าย}" ไม่โชว์ token เต็ม และขั้นที่ 2 ขึ้นรายการ "กลุ่มที่บอทอยู่ (ค้นหาเมื่อ HH:MM)" ให้เลือกเอง
  • เลือกกลุ่ม: ขั้นที่ 2 แสดง "กลุ่ม {ชื่อกลุ่ม}" พร้อมปุ่ม "เปลี่ยนกลุ่ม" และป้ายการ์ดบอกว่ายังเหลือ 1 ขั้น
  • ส่งทดสอบ: กลุ่มทดสอบได้ข้อความ "🧪 ข้อความทดสอบจาก Takra Insight" · ขั้นที่ 3 แสดง "ส่งทดสอบถึงกลุ่มแล้ว · HH:MM" สีเขียว ป้ายการ์ดเป็น "พร้อมแล้ว · ยังปิดการส่ง" และสวิตช์ส่งแจ้งเตือนกดได้
  • เปิดการส่ง + แนบภาพ: ป้ายการ์ดเป็น "เปิดอยู่" · แถวแนบภาพมีกล่องเหลือง "ก่อนเปิด โปรดทราบ" (ภาพออกจากเครื่องไป Telegram · ทุกคนในกลุ่มเห็น · ลบไลฟ์ในแอปแล้วภาพไม่ถูกลบตาม) อยู่ใต้คำอธิบายของแถวนั้นเอง และสวิตช์แนบภาพกดได้หลังเปิดการส่งเท่านั้น
  • ตัวอย่างข้อความ: กรอบหน้าตาเหมือนหน้าแชทของกลุ่ม หัวกรอบเป็นชื่อกลุ่มทดสอบ + "ส่งโดย @{ชื่อบอท} · ตัวอย่าง" · ข้อความแดง "🔴 @your_shop · 📺 ภาพค้าง" มีช่อง "ภาพโฮสต์ตอนเกิดเรื่อง" และวิธีแก้ ①–③ · ตามด้วยข้อความเขียว "🟢 … ✅ ภาพกลับมาแล้ว (หายไป 1 นาที 35 วิ)"
  • เรื่องที่ส่ง: แบ่ง 3 กลุ่มมีจุดสีหน้าหัวกลุ่ม — "ไลฟ์มีปัญหา (5 เรื่อง)" · "โฮสต์และการขาย (4 เรื่อง)" · "กลับมาปกติ (1 เรื่อง)" เป็นรายการคอลัมน์เดียว ใช้ไอคอนไม่ใช่อีโมจิ มีป้าย "ใหม่" ที่ 5 เรื่องใหม่ และบอก "ไม่ส่ง: เรื่องราคา · คอมเมนต์พุ่ง — …"

  • ดาวน์โหลด: หน้าต่างบันทึกตั้งชื่อไฟล์ "recording-{รหัสไลฟ์}.wav" แอปขึ้น "บันทึกไฟล์เสียงแล้ว" ไฟล์เปิดเล่นได้ ยาวเท่าที่แถวแสดง

  • หลังลบ: ขึ้น "ลบเสียงแล้ว 1 ไลฟ์" แถวนั้นหายทันที พื้นที่ที่ใช้ลดลงเท่าขนาดไฟล์ จำนวนไลฟ์ลด 1

🧩 Epic TI-714 · Priority: P1 · E2E · ประเภท: Happy Path (flow ปกติ) · Journey แจ้งเตือน Telegram · ไลฟ์มีปัญหาบนจอ
📌 หมายเหตุ: สเปกขัดกัน: FR148 บอกว่าเจ้าของพื้นที่ทำงานเป็นคนตั้งค่า Telegram แต่โค้ดแสดง "แจ้งเตือน Telegram" และ "สมาชิก" ให้ทุกบัญชีที่เลือกพื้นที่ทำงานแล้ว ตาม TI-598 Owner Q2 เคสนี้ยึดตามโค้ด ถ้า PO ต้องการให้เห็นเฉพาะเจ้าของให้แจ้ง DEV · บิลด์ UAT ไม่เห็น "ผู้ให้บริการ AI" หรือหน้าขยับซ้ายขวา = FAIL

Precondition

  • บัญชีเจ้าของและบัญชีโฮสต์อยู่พื้นที่ทำงานเดียวกัน และเลือกพื้นที่ทำงานนั้นแล้ว
  • ขยายหน้าต่างแอปให้กว้างเต็มจอ

Test Data

  • บัญชีที่ใช้ (UAT): qa.owner@realfactory.co.th · บทบาท "เจ้าของ"

Test Steps

  1. เปิดแอป TAKRA Insight (UAT) แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ กดปุ่มโปรไฟล์ที่มุมล่างของเมนูซ้าย ดูรายการในเมนู แล้วเลือก "ตั้งค่า"
  2. สังเกตหัวหน้า breadcrumb ด้านบน เมนูหลักด้านซ้ายของแอป และรายการในแถบหมวดของหน้าตั้งค่า
  3. กดหมวดในแถบซ้ายทีละหมวดจากบนลงล่างจนครบ แล้วสลับไปมาระหว่าง "ความเป็นส่วนตัว" กับ "สมาชิก" สองสามรอบ สังเกตหัวข้อเนื้อหาและว่าหน้าขยับซ้ายขวาหรือไม่
  4. เปิดเมนูโปรไฟล์ ที่แถว "ธีม" กดรูปพระจันทร์ แล้วกด "ลิขสิทธิ์โอเพนซอร์ส" สังเกตการ์ดเครดิตโมเดล
  5. สลับธีมกลับเป็นสว่าง เปิดเมนูโปรไฟล์ กด "ออกจากระบบ" แล้วเข้าสู่ระบบใหม่ด้วยบัญชีโฮสต์
  6. กดปุ่มโปรไฟล์ที่มุมล่างของเมนูซ้าย เลือก "ตั้งค่า" สังเกตแถบหมวด แล้วกด "สมาชิก" และ "แจ้งเตือน Telegram"

Expected Result

  • เมนูโปรไฟล์: มี "ภาษา" "ธีม" "ตั้งค่า" "ตรวจหาอัปเดต" "ออกจากระบบ" — ไม่มีรายการแยก "ความเป็นส่วนตัว" "ผู้ให้บริการ AI" "แจ้งเตือน Telegram" "สมาชิก" "ลิขสิทธิ์โอเพนซอร์ส" แล้ว · กดแล้วเปิดหน้า "ตั้งค่า" ที่หมวด "ความเป็นส่วนตัว"
  • โครงหน้า: เมนูหลักด้านซ้ายยังอยู่ · breadcrumb เป็นไอคอนหน้าหลัก › "ตั้งค่า" · แถบหมวดเรียง "ความเป็นส่วนตัว" "เสียงที่อัดไว้" "ผู้ให้บริการ AI" "แจ้งเตือน Telegram" "สมาชิก" "ลิขสิทธิ์โอเพนซอร์ส"
  • ทุกหมวด: หมวดที่กดไฮไลต์ หัวข้อตรงหมวด ("ความยินยอมของคุณ" · "เสียงที่อัดไว้" · "ผู้ให้บริการ AI" · "แจ้งเตือนเข้า Telegram" · "สมาชิก" · "ประกาศลิขสิทธิ์โมเดลโอเพนซอร์ส") ไม่มีปุ่ม "‹ ตั้งค่า" แบบเดิม และ breadcrumb ยังเป็น "ตั้งค่า"
  • หน้าไม่กระโดด: สลับหมวดยาว/สั้นแล้วแถบหมวด หัวหน้า และกรอบเนื้อหาอยู่ตำแหน่งเดิม ไม่เลื่อนซ้ายขวา
  • ธีมมืด: การ์ดลิขสิทธิ์ใช้พื้นเข้มตามธีม ชื่อโมเดลและบรรทัด "โดย {ผู้พัฒนา} · {สัญญาอนุญาต}" อ่านออกชัด ไม่มีกล่องพื้นขาวโดด
  • บัญชีโฮสต์: แถบหมวดครบ 6 หมวดเหมือนบัญชีเจ้าของ · "สมาชิก" แสดงรายชื่อพร้อมป้าย "เจ้าของ" เฉพาะแถวเจ้าของ · "แจ้งเตือน Telegram" เปิดหน้า "แจ้งเตือนเข้า Telegram" พร้อม "ตั้งค่าของพื้นที่ทำงาน: {ชื่อพื้นที่ทำงาน}"
