📌 หมายเหตุ: ใช้ไลฟ์จริง ทดสอบด้วยมือ — ใช้บัญชีทดสอบของ QA เปิดไลฟ์เอง · FAIL ถ้าตัวเลขบนแท็บไม่เพิ่ม หรือแถวยังเป็นชื่อเดิม/ไม่มีชิปแท็ก

Precondition

  • บัญชี TikTok ทดสอบของ QA พร้อมเปิดไลฟ์ · มีแท็ก "โปร 11.11" ในพื้นที่ทำงาน
  • จดตัวเลขบนแท็บ "ไลฟ์" ในเมนู "วิเคราะห์ย้อนหลัง" ไว้ก่อนเริ่ม

Test Data

  • บัญชีที่ใช้ (UAT): qa.owner@realfactory.co.th · บทบาท "เจ้าของ"
  • ชื่อยาว: "ไลฟ์ขายครีมกันแดดสูตรใหม่ รอบพิเศษวันเกิดร้าน แจกโค้ดส่วนลดทุกชั่วโมง พร้อมรีวิวเนื้อครีมและวิธีทาให้ซึมไว"

Test Steps

  1. เปิดแอป TAKRA Insight (UAT) แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ ไปที่เมนู "ไลฟ์" วางลิงก์ไลฟ์ของบัญชีทดสอบในช่อง "เพิ่มไลฟ์ที่จะบันทึก" กด "เปิดดูไลฟ์" แล้วกด "เริ่มติดตาม" → "เริ่มบันทึก" รอให้บันทึกอย่างน้อย 5 นาที
  2. ให้โฮสต์กดจบไลฟ์ในแอป TikTok แล้วรอดูแถบด้านบนและป้ายสถานะมุมขวาบนของหน้าบันทึก
  3. กด "ดูรายงาน" ที่แถบด้านบน แล้วดูหัวรายงานและแถบเส้นทาง
  4. กดปุ่มรูปดินสอข้างชื่อไลฟ์ วางชื่อยาวจากข้อมูลทดสอบ แล้วกด Enter
  5. ที่แถว "แท็ก" ใต้หัวรายงาน กด "เพิ่มแท็ก" พิมพ์ "11" เลือก "โปร 11.11" แล้วกด Esc
  6. กด "วิเคราะห์ย้อนหลัง" ในแถบเส้นทาง แล้วดูแท็บ "ไลฟ์" ตัวเลขบนแท็บ และแถวบนสุดของกลุ่ม "วันนี้"

Expected Result

  • ตรวจไลฟ์จบ: แถบด้านบนขึ้น "ไลฟ์จบแล้ว — บันทึกการติดตามเรียบร้อย…" ป้ายมุมขวาบนเปลี่ยนจาก REC เป็น "ไลฟ์จบแล้ว" และมีปุ่ม "ดูรายงาน"
  • ตรวจรายงาน: เปิดรายงานของไลฟ์นี้ แถบเส้นทางเป็น ไอคอนบ้าน › "วิเคราะห์ย้อนหลัง" › <ชื่อไลฟ์> (ไม่มีคำ "วิเคราะห์ไลฟ์ย้อนหลัง")
  • ตรวจแก้ชื่อ: ช่องแก้ชื่อเปิดทับหัวข้อ ขนาดเท่าหัวข้อ ชื่อยาวตัดบรรทัดอ่านได้ทั้งหมด · Enter บันทึกทันที หัวรายงานและแถบเส้นทางเป็นชื่อใหม่ ขึ้นแจ้งเตือน "เปลี่ยนชื่อ session แล้ว"
  • ตรวจติดแท็ก: มีชิป "โปร 11.11" ในแถวแท็กของรายงาน ตัวนับ "1/10 แท็ก" · กด Esc แล้วชิปยังอยู่
  • ตรวจรายการ: กลับมาที่แท็บ "ไลฟ์" ตัวเลขบนแท็บและหัวรอง "N ไลฟ์ที่บันทึกไว้" เพิ่มขึ้น 1 จากที่จดไว้ (แท็บ "คลิป" ไม่เปลี่ยน)
  • ตรวจแถวไลฟ์: แถวบนสุดของกลุ่ม "วันนี้" เป็นไลฟ์นี้ แสดงชื่อใหม่ (ไม่ใช่รหัสไลฟ์) และชิปแท็ก "โปร 11.11" ใต้ชื่อช่อง

📌 หมายเหตุ: FAIL ถ้าแท็กที่ติดไม่ขึ้นบนรายการ/ตัวกรอง/ค้นหา, ชื่อเดิมค้างที่ใดหลังเปลี่ยนชื่อ หรือการลบแท็กทำให้ไลฟ์/คลิปหาย · ล้างหลังเทส: ลบแท็ก "โฮสต์ใหม่" ในเมนู "แท็ก"

Precondition

  • พื้นที่ทำงานมีไลฟ์ที่วิเคราะห์แล้วอย่างน้อย 3 ไลฟ์ และคลิปอย่างน้อย 1 คลิป
  • ยังไม่มีแท็กชื่อ "โปร 11.11", "โฮสต์ใหม่" และ "โปร 11.11 รอบเย็น"

Test Data

  • บัญชีที่ใช้ (UAT): qa.owner@realfactory.co.th · บทบาท "เจ้าของ"

Test Steps

  1. เปิดแอป TAKRA Insight (UAT) แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ ไปที่เมนู "แท็ก" สร้างแท็ก "โปร 11.11" และ "โฮสต์ใหม่" ด้วยช่อง "ชื่อแท็กใหม่ เช่น โปร 12.12" กับปุ่ม "สร้างแท็ก" แล้วสังเกตตาราง
  2. ไปที่เมนู "วิเคราะห์ย้อนหลัง" แท็บ "ไลฟ์" เปิดรายงานไลฟ์ L1 กด "เพิ่มแท็ก" ใต้หัวรายงาน พิมพ์ "11" แล้วเลือก "โปร 11.11" · ทำซ้ำกับไลฟ์ L2 โดยเลือก "โฮสต์ใหม่" และกับคลิป C1 (แท็บ "คลิป") โดยเลือก "โปร 11.11"
  3. กลับมาที่รายการ "วิเคราะห์ย้อนหลัง" ดูชิปแท็กใต้ชื่อช่องบนแถว L1, L2 และ C1
  4. แท็บ "ไลฟ์" กดปุ่ม "แท็ก" ติ๊กทั้ง "โปร 11.11" และ "โฮสต์ใหม่" แล้วกดแท็บ "คลิป" ดูรายการ จากนั้นกด "ล้างตัวกรอง" และพิมพ์ "11.11" ในช่องค้นหาแล้วดูทั้งแท็บ "คลิป" และ "ไลฟ์"
  5. ไปที่เมนู "แท็ก" กดตัวเลขคอลัมน์ "ไลฟ์" ของแถว "โปร 11.11" แล้วสังเกตหน้าที่เปิด
  6. กลับไปเมนู "แท็ก" ที่แถว "โปร 11.11" กด "เปลี่ยนชื่อ" แก้เป็น "โปร 11.11 รอบเย็น" กด "บันทึก" แล้วเปิดรายการและรายงานของ L1 ดูชื่อแท็ก
  7. กลับไปเมนู "แท็ก" กด "ลบ" ที่แถว "โปร 11.11 รอบเย็น" อ่านกล่องยืนยัน กด "ลบแท็ก" แล้วไปดูรายการ "วิเคราะห์ย้อนหลัง" ทั้งสองแท็บ

Expected Result

  • ตรวจการสร้าง: ขึ้น "สร้างแท็ก “โปร 11.11” แล้ว" (และของ "โฮสต์ใหม่") ทั้งสองแถวมีป้าย "ยังไม่ได้ใช้" ตัวเลขไลฟ์/คลิปเป็น 0
  • ตรวจการติดแท็กในรายงาน: พิมพ์ "11" แล้วเห็น "โปร 11.11" ในรายการแนะนำ เลือกแล้วชิปขึ้นในแถว "แท็ก" ใต้หัวรายงานทันที ทั้งรายงานไลฟ์และรายงานคลิป
  • ตรวจชิปบนรายการ: แถว L1 มี "โปร 11.11" · L2 มี "โฮสต์ใหม่" · C1 ในแท็บ "คลิป" มี "โปร 11.11" · กดชิปแล้วเปิดรายงานตามปกติ
  • ตรวจตัวกรองและค้นหา: แท็บ "ไลฟ์" เหลือ L1 และ L2 (มีแท็กใดก็ได้) มีแถว "กรองด้วยแท็ก (มีอันใดก็ได้):" และ "แสดง 1–2 จาก 2 ไลฟ์" · แท็บ "คลิป" ใช้ตัวกรองเดียวกันเหลือ C1 · ค้น "11.11" แล้วเจอ L1 และ C1 ด้วยชื่อแท็ก
  • ตรวจตัวเลขในเมนู "แท็ก": แถว "โปร 11.11" เป็น ไลฟ์ 1 · คลิป 1 · กดเลขไลฟ์แล้วเปิดแท็บ "ไลฟ์" ที่กรองแท็กนี้ไว้ ช่องค้นหาถูกล้าง แสดง L1 รายการเดียว
  • ตรวจการเปลี่ยนชื่อ: ขึ้น "เปลี่ยนชื่อแท็กแล้ว — ทุกไลฟ์และคลิปที่ติดไว้เปลี่ยนตาม" และแถวบนรายการ แถว "แท็ก" ในรายงาน L1 และ C1 เป็น "โปร 11.11 รอบเย็น" ไม่เหลือชื่อเดิม
  • ตรวจการลบ: กล่อง "ลบแท็ก “โปร 11.11 รอบเย็น”?" เขียน "แท็กนี้จะถูกเอาออกจาก 1 ไลฟ์ และ 1 คลิป" และ "ไลฟ์และคลิปไม่ถูกลบ · ลบแล้วกู้คืนไม่ได้" · ลบแล้วขึ้น "ลบแท็ก “โปร 11.11 รอบเย็น” แล้ว" · L1 และ C1 ยังอยู่ในรายการแต่ไม่มีชิปแท็กนี้

  2. กดแท็บ "คลิป" รอรายการขึ้น แล้วกดกลับแท็บ "ไลฟ์"
  3. พิมพ์คำที่ไม่มีในรายการลงช่องค้นหา แล้วสังเกตตัวเลขบนทั้งสองแท็บอีกครั้ง

Expected Result

  • ตัวเลขบนแท็บ "ไลฟ์" เท่ากับ N ในหัวรอง "N ไลฟ์ที่บันทึกไว้" และตัวเลขบนแท็บ "คลิป" เท่ากับ N ใน "N คลิปที่วิเคราะห์ไว้"
  • ก่อนเปิดแท็บคลิปครั้งแรก แท็บ "คลิป" อาจยังไม่มีตัวเลข (ไม่ขึ้นเลข 0) — หลังเปิดแท็บคลิปแล้วตัวเลขขึ้นและคงอยู่แม้กลับมาแท็บไลฟ์
  • ค้นหาหรือกรองจนรายการว่าง ตัวเลขบนแท็บยังเป็นจำนวนทั้งหมดเท่าเดิม

  • กด Tab ออกจากแถวแท็บไปที่ตัวกรองถัดไปเลย ไม่ต้องผ่านแท็บที่ไม่ได้เลือก
