🧩 Epic TI-713 · Priority: P0 · E2E · ประเภท: Happy Path (flow ปกติ) · Journey วิเคราะห์คลิป TikTok / Facebook — วางลิงก์ถึงรายงาน · ลิงก์มีปัญหา
📌 หมายเหตุ: FAIL ถ้ามีขั้นค้าง "กำลังทำ" หลังรายงานเปิด หรือชื่อคลิปไม่ตรงกันระหว่างรายงาน คลิปล่าสุด และวิเคราะห์ย้อนหลัง · ตัวเลขเวลาขึ้นกับความยาวคลิปจริง (≈ ความยาว + 5 ถึง + 30 วินาที)

Precondition

  • แอปล็อกอิน TikTok ไว้แล้ว
  • ให้ความยินยอมอ่านสีหน้าและฟังเสียงแล้ว
  • ไม่มีไลฟ์กำลังบันทึกอยู่ในแอป

Test Data

  • บัญชีที่ใช้ (UAT): qa.owner@realfactory.co.th · บทบาท "เจ้าของ"
  • ลิงก์คลิป TikTok สาธารณะของบัญชีทดสอบ QA ยาวประมาณ 30 วินาที เห็นหน้าคนพูด และมีคนพูด 2 เสียงขึ้นไป

Test Steps

  1. เปิดแอป TAKRA Insight (UAT) แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ ไปที่เมนู "คลิป" แล้วกดปุ่ม "?" ท้ายช่อง "วางลิงก์คลิป" อ่านรูปแบบลิงก์ในแผงที่เปิด แล้วปิดแผง
  2. วางลิงก์คลิป TikTok แล้วกด "เปิดคลิป" สังเกตข้อมูลคลิป ปุ่ม และบรรทัดเวลาใต้ปุ่มในหน้าตรวจคลิป
  3. กด "เริ่มวิเคราะห์" แล้วดูหน้า "วิเคราะห์คลิป" จนเสร็จ สังเกตบรรทัดเวลาและสถานะของ 3 ขั้นตอน
  4. เมื่อรายงานเปิดเอง สังเกตหัวรายงานและ "สถิติของคลิป" ในส่วน "ภาพรวม"
  5. กดแท็บ "บทพูด" แล้วอ่านหัวการ์ดและบรรทัดข้อมูลเหนือช่องค้นหา
  6. ไปที่เมนู "คลิป" สังเกตแถวบนสุดของ "คลิปที่วิเคราะห์ล่าสุด" แล้วกด "ดูทั้งหมด"
  7. ในหน้า "วิเคราะห์ย้อนหลัง" แท็บ "คลิป" กดแถวคลิปนี้ แล้วกด "วิเคราะห์ย้อนหลัง" ที่แถบเส้นทางด้านบน สังเกตแท็บที่ถูกเลือก

Expected Result

  • แผงลิงก์: หัวแผง "ลิงก์คลิปที่ใช้ได้" มีรูปแบบลิงก์ TikTok (tiktok.com/@…/video/… · vt.tiktok.com/…) และ Facebook ปิดแผงแล้วใช้ช่องต่อได้
  • ตรวจคลิป: เห็นปก "โดย @ชื่อช่อง" ความยาว ยอดวิว/ไลก์/คอมเมนต์ มีแค่ปุ่ม "เริ่มวิเคราะห์" (ไม่มีปุ่มอัปโหลด) และ "ใช้เวลาประมาณ 35–60 วินาที" ก่อนกดเริ่ม
  • ความคืบหน้า: 3 ขั้น "ดึงวิดีโอ" → "ถอดเสียง" → "อ่านคอมเมนต์" เปลี่ยนสถานะเป็นคำ "รอ" / "กำลังทำ" / "เสร็จ" และเวลานับถอยหลัง "เหลืออีกประมาณ …" ไม่ติดลบ แล้วเปิดรายงานเอง
  • รายงาน: หัวรายงานมีคำว่า "TikTok" ข้างไอคอน @ชื่อช่อง ป้าย "วิเคราะห์เสร็จ" และ "สถิติของคลิป" 5 ช่อง "ยอดดู" "ไลก์" "คอมเมนต์" "แชร์" "บันทึก" กำกับ "ณ เวลาวิเคราะห์ …"
  • บทพูด: หัวการ์ด "บทพูดของคลิป" และบรรทัดข้อมูลพูดว่า "คลิปนี้" (เช่น "ระบบได้ยินอย่างน้อย 2 เสียงในคลิปนี้ …") ไม่มีคำว่า "ไลฟ์นี้"
  • คลิปล่าสุด: แถวบนสุดเป็นคลิปนี้ ชื่อเดียวกับหัวรายงาน มีป้าย "คลิป TikTok" และวันที่
  • วิเคราะห์ย้อนหลัง: "ดูทั้งหมด" เปิดหน้า "วิเคราะห์ย้อนหลัง" ที่แท็บ "คลิป" แถวคลิปนี้มีป้าย "คลิป TikTok" ชื่อเดียวกับรายงาน
  • แถบเส้นทาง: ในรายงานเป็น "วิเคราะห์ย้อนหลัง" › ชื่อคลิป กดแล้วกลับมาหน้า "วิเคราะห์ย้อนหลัง" ที่แท็บ "คลิป"

▸TC-JRN-A.5 วิเคราะห์คลิปไม่สำเร็จ แล้วอัปโหลดไฟล์คลิปเองตามที่แอปเสนอ → เลือกไฟล์ผิดแก้ได้ และได้รายงานจากไฟล์ Exception E2E P1 รอเทส รอเทส
วิเคราะห์คลิปไม่สำเร็จ แล้วอัปโหลดไฟล์คลิปเองตามที่แอปเสนอ → เลือกไฟล์ผิดแก้ได้ และได้รายงานจากไฟล์
🧩 Epic TI-713 · Priority: P1 · E2E · ประเภท: Exception (เน็ตหลุด · ระบบภายนอกผิดปกติ · timeout) · Journey วิเคราะห์คลิป TikTok / Facebook — วางลิงก์ถึงรายงาน · ลิงก์มีปัญหา
📌 หมายเหตุ: ถ้ากด "เริ่มวิเคราะห์" ตอนไม่มีเน็ตแล้วขึ้นข้อความเตือนในหน้าตรวจคลิปแทน ให้เปิดเน็ต กดเริ่มใหม่แล้วตัดเน็ตทันทีระหว่าง "ตอนนี้: อ่านข้อมูลคลิป" · FAIL ถ้าหน้าค้างหมุนหลังตัดเน็ต หรือหน้าต่างเลือกไฟล์ไม่เปิดเองหลังกด "อัปโหลดไฟล์คลิปเอง"

Precondition

  • แอปล็อกอิน TikTok ไว้แล้ว และให้ความยินยอมอ่านสีหน้าและฟังเสียงแล้ว
  • ไม่มีไลฟ์กำลังบันทึกอยู่ในแอป
  • มีไฟล์วิดีโอของคลิปที่จะทดสอบเก็บไว้ในเครื่อง (ดูข้อมูลทดสอบ)

Test Data

  • บัญชีที่ใช้ (UAT): qa.owner@realfactory.co.th · บทบาท "เจ้าของ"
  • ลิงก์คลิป TikTok สาธารณะของบัญชีทดสอบ QA ยาวประมาณ 30 วินาที เห็นหน้าคนพูด
  • ไฟล์วิดีโอของคลิปเดียวกัน (mp4 · mov · m4v · webm ไม่เกิน 200 MB · ความยาวต่างจากคลิปไม่เกิน 2 วินาที)
  • ไฟล์วิดีโอยาว 60 วินาที ไม่เกิน 200 MB
  • ไฟล์ข้อความที่เปลี่ยนนามสกุลเป็น .mp4

Test Steps

  1. เปิดแอป TAKRA Insight (UAT) แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ ไปที่เมนู "คลิป"
  2. วางลิงก์คลิป TikTok ที่ยาวประมาณ 30 วินาที กด "เปิดคลิป" รอการ์ดข้อมูลคลิปขึ้น แล้วสังเกตปุ่มบนหน้า
  3. ปิด Wi-Fi/ถอดสายแลนของเครื่อง แล้วกด "เริ่มวิเคราะห์" รอจนหน้า "วิเคราะห์คลิป" หยุดทำงาน อ่านข้อความ สถานะ 3 ขั้น และปุ่มบนหน้า แล้วเปิดเน็ตกลับ
  4. กด "อัปโหลดไฟล์คลิปเอง" สังเกตหน้าที่เปิดและหน้าต่างเลือกไฟล์ที่ขึ้นเอง แล้วเลือกไฟล์ข้อความที่เปลี่ยนนามสกุลเป็น .mp4
  5. กด "อัปโหลดไฟล์คลิป" เลือกไฟล์วิดีโอยาว 60 วินาที อ่านกล่องที่ขึ้น แล้วกด "เลือกไฟล์ใหม่"
  6. กด "อัปโหลดไฟล์คลิป" อีกครั้ง แล้วเลือกไฟล์วิดีโอของคลิปนี้ที่ความยาวตรงกัน
  7. ดูหน้า "วิเคราะห์คลิป" จนรายงานเปิดขึ้นเอง แล้วสังเกตหัวรายงานและชิป "โฮสต์"

Expected Result

  • ก่อนเริ่ม: หน้าตรวจคลิปมีแค่ปุ่ม "เริ่มวิเคราะห์" ไม่มีปุ่มอัปโหลดไฟล์
  • วิเคราะห์ไม่สำเร็จ: หน้าไม่ค้างหมุน ขึ้นเหตุผลภาษาไทย เช่น "เชื่อมต่อ TikTok ไม่ได้ ตรวจอินเทอร์เน็ตแล้วลองอีกครั้ง" ไม่มีขั้นไหนค้าง "กำลังทำ" (เป็น "หยุด" / "ไม่ได้ทำ") พร้อม "ลองวิเคราะห์อีกครั้ง หรือถ้ามีไฟล์คลิปนี้อยู่แล้ว อัปโหลดไฟล์เองได้" และปุ่ม "ลองวิเคราะห์อีกครั้ง" "อัปโหลดไฟล์คลิปเอง" "กลับหน้าหลัก"
  • อัปโหลดไฟล์คลิปเอง: กลับหน้าตรวจคลิปเดิม หน้าต่างเลือกไฟล์ของเครื่องเปิดเองทันที หน้ามีปุ่ม "เริ่มวิเคราะห์" "อัปโหลดไฟล์คลิป" และ "ถ้ามีไฟล์คลิปนี้อยู่แล้ว ใช้ไฟล์ได้เลย (mp4 · mov · m4v · webm ไม่เกิน 200 MB)"
  • ไฟล์ที่ไม่ใช่วิดีโอ: ขึ้น "ไฟล์นี้ไม่ใช่วิดีโอ หรือเปิดอ่านไม่ได้" ไม่เริ่มวิเคราะห์ และปุ่ม "อัปโหลดไฟล์คลิป" ยังอยู่ให้เลือกใหม่
  • ความยาวไม่ตรง: ขึ้นกล่องถาม "ความยาวไฟล์ไม่ตรงกับคลิปนี้ (ไฟล์ 60 วินาที · คลิป 30 วินาที) ใช้ไฟล์นี้ต่อไหม" ปุ่ม "เลือกไฟล์ใหม่" / "ใช้ไฟล์นี้" · "เลือกไฟล์ใหม่" ปิดกล่องโดยยังไม่เริ่มวิเคราะห์
  • ไฟล์ที่ถูก: ไม่ถามเรื่องความยาว เริ่มวิเคราะห์ทันทีและเปิดหน้า "วิเคราะห์คลิป"
