▸TC-HUD.1 เริ่มบันทึกแล้วต้องมีหน้าต่าง HUD ลอยขึ้น พร้อมบอกว่ากำลังเฝ้าไลฟ์อยู่ UI P0 รอเทส
เริ่มบันทึกแล้วต้องมีหน้าต่าง HUD ลอยขึ้น พร้อมบอกว่ากำลังเฝ้าไลฟ์อยู่
Priority: P0 · UI · hud-overlay · ขั้นที่ 1 · Epic 2

Precondition

  • เปิดแอปเดสก์ท็อป TAKRA Insight (บิลด์ UAT) แล้วล็อกอินด้วยบัญชี UAT ที่แพ็กเกจยังไม่หมดอายุ
  • ตอนตั้งค่าครั้งแรกเลือก "ยินยอมและเริ่มใช้งาน" ไว้ (ไม่ได้เลือก "ใช้ต่อแบบคอมเมนต์อย่างเดียว")
  • มีช่องที่กำลังไลฟ์อยู่จริงสำหรับทดสอบ และมีคนช่วยพิมพ์คอมเมนต์ในไลฟ์นั้นได้

Test Steps

  1. เปิดแอป TAKRA Insight แล้วล็อกอินด้วยบัญชี UAT
  2. ที่หน้า "ภาพรวม" วางลิงก์ไลฟ์ของช่องทดสอบในช่อง "วาง URL ไลฟ์ หรือค้นหาชื่อช่อง…" แล้วกด "เปิดดูไลฟ์"
  3. พอไลฟ์ขึ้นในเบราว์เซอร์ในตัวแล้ว กด "เริ่มติดตาม" ตั้งชื่อในกล่อง "ตั้งชื่อเซสชัน" แล้วกด "เริ่มบันทึก"
  4. มองหาหน้าต่างเล็กที่ลอยอยู่มุมจอ (HUD) แล้วอ่านข้อความบนนั้นตอนที่ยังไม่มีการแจ้งเตือนใดๆ

Test Data

  • ไลฟ์ที่มีคนพูดหน้ากล้องเห็นใบหน้าชัด

Expected Result

  • มีหน้าต่างเล็กลอยอยู่เหนือหน้าจอ (ไม่มีแถบชื่อหน้าต่าง) ตั้งแต่เริ่มบันทึก
  • ตอนที่ยังไม่มีสัญญาณอะไร มีป้ายเล็กเขียนว่า "กำลังเฝ้าไลฟ์อยู่" — ไม่ใช่มุมจอว่างเปล่า และยังไม่มีการ์ดแจ้งเตือน
  • ใต้ป้ายมีกล่องสีเข้มแสดงอีโมจิอารมณ์ + ตัวเลขคู่กับคำว่า "พลัง" และบรรทัดล่างสุด "🔒 ซ่อนจากไลฟ์ของคุณ"
  • ถ้ายังจับใบหน้าไม่ได้ กล่องนั้นขึ้น "กำลังรอใบหน้า…" และตัวเลขเป็น "—"
  • ที่มา: Epic 2 · Story 2.1 · FR25/FR27

▸TC-ALT.7 กล่อง "คิวแจ้งเตือน" ต้องเริ่มที่ศูนย์ และหายไปเมื่อจบการติดตาม UI P1 รอเทส
กล่อง "คิวแจ้งเตือน" ต้องเริ่มที่ศูนย์ และหายไปเมื่อจบการติดตาม
Priority: P1 · UI · alert-controls · ขั้นที่ 2 · Epic 2

Precondition

  • เปิดแอปเดสก์ท็อป TAKRA Insight (บิลด์ UAT) แล้วล็อกอินด้วยบัญชี UAT ที่แพ็กเกจยังไม่หมดอายุ
  • ตอนตั้งค่าครั้งแรกเลือก "ยินยอมและเริ่มใช้งาน" ไว้ (ไม่ได้เลือก "ใช้ต่อแบบคอมเมนต์อย่างเดียว")
  • มีช่องที่กำลังไลฟ์อยู่จริงสำหรับทดสอบ และมีคนช่วยพิมพ์คอมเมนต์ในไลฟ์นั้นได้

Test Steps

  1. เปิดแอป TAKRA Insight แล้วล็อกอินด้วยบัญชี UAT
  2. ที่หน้า "ภาพรวม" วางลิงก์ไลฟ์ของช่องทดสอบในช่อง "วาง URL ไลฟ์ หรือค้นหาชื่อช่อง…" แล้วกด "เปิดดูไลฟ์"
  3. พอไลฟ์ขึ้นในเบราว์เซอร์ในตัวแล้ว กด "เริ่มติดตาม" ตั้งชื่อในกล่อง "ตั้งชื่อเซสชัน" แล้วกด "เริ่มบันทึก"
  4. ทันทีหลังเริ่มบันทึก ดูกล่อง "คิวแจ้งเตือน" ในแถบ "Insight แบบเรียลไทม์" ทางขวา
  5. กดปุ่ม "หยุดติดตาม" แล้วยืนยัน จากนั้นดูแถบขวาอีกครั้ง

Test Data

  • เซสชันใหม่ที่ยังไม่มีการแจ้งเตือนใดๆ

Expected Result

  • ตอนเริ่ม กล่อง "คิวแจ้งเตือน" แสดง "รับทราบ" = 0 · "เลื่อน" = 0 · บรรทัด "ปิดชนิด:" เป็น "—"
  • เมื่อหยุดติดตาม/ไลฟ์จบ กล่อง "คิวแจ้งเตือน" หายไปจากแถบขวา (สรุปย้อนหลังไปดูที่หน้ารายงานของเซสชันแทน)
