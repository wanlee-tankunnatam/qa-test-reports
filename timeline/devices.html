แก้ในหน้าได้เลย — ข้อมูลเก็บในไฟล์นี้ (บล็อก store-data) และบันทึกขึ้น GitHub อัตโนมัติ · เปิดได้ทุกเครื่องผ่าน GitHub Pages (cache ~10 นาที) · ปุ่ม "📥 นำเข้าจากเครื่อง" มีคำสั่งดึงรายชื่อโปรแกรมสำหรับ Mac/Windows (กรองเฉพาะ TAKRA ให้เอง)

macOS (Terminal)
for a in /Applications/*.app; do n=$(basename "$a" .app); v=$(defaults read "$a/Contents/Info.plist" CFBundleShortVersionString 2>/dev/null); printf '%s\t%s\n' "$n" "$v"; done | pbcopy
Windows (PowerShell)
Get-ItemProperty HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*, HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*, HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\* | Where-Object DisplayName | Sort-Object DisplayName -Unique | ForEach-Object { "$($_.DisplayName)`t$($_.DisplayVersion)" } | Set-Clipboard
