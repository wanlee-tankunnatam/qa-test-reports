บั๊กค้างรอบส่งงาน

บั๊กที่ยังไม่ปิดจากทุกโปรเจกต์ใน Jira แยกตามรอบส่ง แล้วแยกตามผู้รับผิดชอบ · ในแต่ละคนเรียงตามขั้นที่ลูกค้าเจอใน user journey · ข้อมูล ณ 13 พ.ย. 2026 13:00 น. (อัปเดตอัตโนมัติ 09:00 / 13:00 หรือกดปุ่มดึงข้อมูลจาก Jira)

รอบ Dev ระดับ ขอบเขตงาน สถานะ
แตะรหัสตั๋วเพื่อเปิดใน Jira · ขอบเขตงาน (เฉพาะ TI · 29 ก.ย.): "UI อย่างเดียว" = แก้ที่หน้าจอในแอป ไม่ต้องแตะ API เลย · "แตะ API / ระบบ" = ต้องแก้ backend, engine, การเรียก API หรือตรรกะฝั่ง main · "เทส / เครื่องมือ" = spec, build, สคริปต์ ไม่ใช่ตัวแอป — แยกจากรายละเอียดในตั๋ว Jira · Insight (TI) ใบที่ไม่มีป้ายวันที่รวมไว้ใน "ยังไม่มีรอบ" · รอบของ TAKRA = ป้ายวันที่ในตั๋ว Jira (ซิงก์ 7 ต.ค.) · ป้ายที่เลยวันไปแล้วแสดงตามจริง · ใบที่ไม่มีป้ายอยู่ "ยังไม่มีรอบ"
